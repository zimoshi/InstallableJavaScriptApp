# Installable JavaScript App
The newest way to install a webpage as a app!

## How to install
1. Click "Fork".
2. Follow the instructions.
3. Open the <a href="index.html">index.html</a> file and click the pen button.
4. Replace the <title>My Game</title> in the file to <title>**Your App Name**</title> (replace the "your app name" with your app name)
5. Replace the "https://website/website" in <iframe src="https://website/website"></iframe> with your website.
6. Open <a href="manifest.json">manifest.json</a> (and click the pen button)
7. Replace the "MyApp" in "name" and "short_name" with your app name. No spaces!
8. Replace the "MyApp." in "description" with the description.
9. Now, go to <a href="https://favicon.io/favicon-converter#generate-from-image">Favicon.io</a> and upload your logo image.
10. Press "Download favicon package" and extract the zip file.
11. Then, upload all files in the folder that was extracted to the GitHub repository.
12. Then, deploy it to Cloudflare (or something else).
13. You're finished!!

## How to test
1. Go to the deployed link and click on the gear icon. (Make sure to use Chrome/a Chromium-based browser!)
2. Then, if it worked, you should see a button that says "Install as app".
3. Click on the button and follow the instructions.
4. You have installed your app!

## How to make multiple forks
1. Click <a href="https://github.com/zimoshi/InstallableJavaScriptApp/raw/refs/heads/main/InstallableJavaScriptApp.zip">here</a> to download the zip file.
2. Unzip the zip file.
3. Create a new repo.
4. Upload the files.
5. You're finished!!
